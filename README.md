# Corum

Evidence-aware, dependence-aware consensus for reliable multi-model decisions.

Corum calibrates imperfect reviewers, discounts correlated evidence, and returns
`PASS`, `FAIL`, or `DEFER` when the available evidence is insufficient. The project is
being developed as an independent, reproducible open-source implementation by Franz Xu.

## Status

The MVP is under active development. Its first release will include a tested statistical
core, controlled simulation benchmarks, an adaptive low-cost reviewer cascade, and a
reproducible HaluEval evaluation path. Synthetic results and real-model results will be
reported separately.
